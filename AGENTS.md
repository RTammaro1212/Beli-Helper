# Auto Beli UI guidelines

- Use Crimson Pro from `next/font/google` as the primary typeface.
- Keep the canvas clean white with pale gray-green surfaces for cards and panels.
- Use the green accent from the reference prototype for actions, statuses, and emphasis.
- Never use drop shadows.
- Never use borders, including around cards, inputs, buttons, and controls.
- Never use rounded corners; keep all surfaces and controls square.
- Do not nest cards inside cards. Use flat surfaces with spacing and typography to create hierarchy.
- Represent photo clusters with stacked rectangular photo shapes; do not use folder or file icons.
- Never use all-caps text in the interface.
- Do not number stages or entries as a ranking system; ranking is an action on a ready entry.
- Review entries must expose a category choice and a three-way feeling choice before the mock rank action becomes available.
- Keep the prototype intentionally lightweight: interactions can be local mock states until product logic is requested.
